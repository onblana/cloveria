# Cloveria

클로버의 행운이 깃든 시골 마을에서 직접 농사지은 재료로 요리를 만들어 식당을 경영하는 웹 게임.
모바일 브라우저를 주 타깃으로 만듭니다.

**플레이: https://cloveria.vercel.app**

## 기술 스택

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · IndexedDB(저장) · Vercel 배포

## 진행 상황

플레이 가능한 코어 루프까지 구현돼 있습니다. 하루는 아침·점심·오후·저녁·밤 5단계로 나뉘고, 농사 단계에서 씨앗을 심어 기르고 장사 단계에서 주문을 받아 요리를 냅니다. 단계는 버튼으로 직접 넘깁니다.
